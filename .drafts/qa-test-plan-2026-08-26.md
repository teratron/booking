# Full-funnel test plan — anonymous visitor to chief administrator

Every reachable action across the public site, the owner cabinet, the staff
panel and the versioned API, ordered as one continuous walkthrough: an
anonymous visitor arrives, an owner signs in, staff moderate, the chief
administrator runs the portal, and an API consumer reads it.

Each row names where the action lives in the code, what should happen, and
what would plausibly be broken there — the last column is what makes a row
worth executing rather than ticking.

**615 actions** across **15 stages**, derived by reading the
routes, Livewire components, Blade views, Filament resources, policies and API
controllers — not from a written description of them.
